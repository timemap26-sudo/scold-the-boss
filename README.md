# 罵老闆 Scold the Boss 🤬

一個網頁小遊戲：卡通老闆坐在老闆桌後面，你可以 **用麥克風罵他** 或 **打字罵他**，
他會一路從「淡定 → 心虛 → 狂道歉 → 快哭了 → 大哭 → 崩潰」，崩潰值滿 100% 就 K.O.！

線上玩：https://timemap26-sudo.github.io/scold-the-boss/

## 玩法
- **打字**：在輸入框打字按「罵！」，或點下方的快捷罵句。
- **麥克風**：按「開麥克風罵」，用中文罵他（使用瀏覽器語音辨識，建議 Chrome / Edge / Safari）。越大聲傷害越高。
  不支援語音辨識的瀏覽器會改用「音量模式」：大吼就能打到老闆。
- 罵到「加班、薪水、年終、休假、開會」等關鍵字，老闆會特別心虛地回應。
- 停太久不罵，老闆會慢慢恢復囂張。
- 老闆會用語音回嘴（可切換靜音）：台灣腔男聲，使用免費的 Microsoft Edge 神經語音 `zh-TW-YunJheNeural`（雲哲），每句台詞都預先錄成 `voice/*.mp3`，音調語速會隨崩潰程度變化。
- **換成老闆的臉**：按「📷 上傳老闆照片」，會自動偵測臉並對準（可再拖曳／縮放／旋轉微調），
  老闆就會變成照片裡的臉，而且表情會跟著崩潰程度變化：得意 → 皺眉冒汗 → 眉頭下垂 → 嘴角下垂含淚 → 大哭 → 藍臉轉圈眼崩潰。
  照片只在你的瀏覽器裡處理，不會上傳到任何地方；會記在瀏覽器裡，下次打開還在，可按「改回卡通老闆」移除。

## 開發
純靜態單一檔案 `index.html`，直接用瀏覽器開啟即可。推送到 `main` 後由 GitHub Actions 自動部署到 GitHub Pages。

修改或新增老闆台詞後，重新產生語音檔（檔名是台詞的 hash，找不到檔案時會退回瀏覽器內建語音）：

```bash
pip install edge-tts
python3 tools/gen_voice.py
```
